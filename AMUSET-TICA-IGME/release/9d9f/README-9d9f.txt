!!!
9d9f_tICA_AT_IGME-comparison.ipynb:
# Uses sorted tICs in "9d9f_inv_2tics.npy", which has top 2 tICs for overall 
# 40 trajectories with 50,000 frames in each (1 frame = 2 ps) and apply 
# tICA, AMUSET-TICA, AMUSET-TICA-IGME methods for doing comparison. Koopman 
# matrices for from lag_time = 1 to lag_time = 300 frames in AMUSET-TICA are 
# saved in "9d9f_Ks.npy". ITS comparisons are saved in "Panel_1d_ITS.npz". 
# Note: the golden standard in ITS comparison is not reliable!!! 
# y_max, y_min = 470, 430 frames need more validation!!!
!!!

9d9f_RMSE.ipynb:
# Goes over hyperparameters tau_k and L for fitting and the results are saved
# to "Panel_1e*_RMSE.npz".

9d9f_cv_plots.ipynb:
# Generates CV against theta plots from 5 methods. 1. GraphVAMPnets (using 
# "graphvampnets_cvs_50epochs.npy"); 2. Unsorted tICA ("9d9f_pwd_2tics.npy"); 
# 3. Sorted tICA ("9d9f_inv_2tics.npy"); 4. AMUSET-TICA (at lag_time = 86 
# frames); 5. AMUSET-TICA-IGME (tau_k=65, L=20, propagation steps=100 frames).
# Output all the CV results into "9d9f_[Method name]_mode[1/2]_data.txt".
# Also contains usage of theta trajectories (folder 9d9f_theta) and generation 
# of SVD results ("9d9f-dim25-SVD-Vt.npy").

9d9f-tICsGaussian_n_bootstraping.ipynb:
# Two parts. 1. Bootstrapping for CK test; 2. Plotting the tICs expansions.

9d9f-AllPlots.ipynb:
# Collects the data from all previous codes and generates the plots ready for
# publications. Has color-friendly plans, and designs neat plots.

========================================

Data file

9d9f_inv_2tics.npy:
# 3D np.array of shape (40, 50001, 2) containing tICs. Sorted matrix version. 

9d9f_pwd_2tics.npy:
# 3D np.array of shape (40, 50001, 2) containing tICs. Original unsorted 
# matrix version. 

9d9f-dim25-SVD-Vt.npy:
# Save the V^T matrices from SVD decomposition results which are ready for 
# generating CVs of rank 25. The CVs are generated by np.matmul(Vt, vrK), 
# in which vrK is the sorted eigenvector matrix from diagonalizing Koopman 
# matrix.

9d9f_Ks.npy:
# Koopman matrices generated by AMUSET-TICA for rank 25 at lag times ranging
# from 1 to 300 frames.

9d9f_theta\:
# Theta 1 and 2 for CV plotting. See usage in 9d9f_RMSE.ipynb.

Koopman_bootstrap.npz:
# CK test intermediate results. Has 3 keys: "Koop_boot" saves a 4D np.array 
# which is the matrices during bootstrapping; "lag" saves the corresponding
# lag times; "note" is the note. See 9d9f-tICsGaussian_n_bootstraping.ipynb,
# which is the notebook generating this .npz file, for more information.

random-number-40.txt:
# Random numbers, generated by website random.org. Used in CK test. Check 
# 9d9f-tICsGaussian_n_bootstraping.ipynb for more information about usage.

graphvampnets_cvs_50epochs.npy:
# From GraphVAMPnets paper. Top 2 CVs from GraphVAMPnets method.

9d9f_*-mode[1/2]_data.txt:
# Data files for CV plotting, i.e. CVs against RMSD plots for top 2 CVs. 
# Generated by 9d9f_cv_plots.ipynb.

Panel_*.npz:
# These files are results for each plot, and they are finally used for plots.
# Notebook FIP35-AllPlots.ipynb take them as input.

9d9f-molecule.png:
# 9d9f dimer molecules. Created by ChemDraw.

\svg_files\*.svg:
# Output from 9d9f-AllPlots.ipynb, combined together into figures shown in the
# paper draft with Inkscape.
