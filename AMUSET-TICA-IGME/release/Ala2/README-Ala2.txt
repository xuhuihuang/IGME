Jupyter Notebook

Ala2-dim25-KoopmanGeneration.ipynb:
# Generates rank 25 Koopman matrices and saves them into Ks25.npy. Also saves
# comparisons with rank 125 and rank 343.

Ala2-RMSE_n_CV.ipynb:
# Runs over many combinations of tau_k and L to identify the best choices. 
# Uses them to build the CVs and also the plots. The ITS comparisons with
# previous methods like tICA and AMUSET-tICA are also in.

Ala2-tICsGaussian_n_bootstraping.ipynb:
# Two parts. 1. Bootstrapping for CK test; 2. Plotting the tICs expansions.

Ala2-AllPlots.ipynb:
# Collects the data from all previous codes and generates the plots ready for
# publications. Has color-friendly plans, and designs neat plots.

========================================

Data file

Ala-125-SVD-Vt.npy, Ala-25-SVD-Vt.npy, Ala-343-SVD-Vt.npy:
# Save the V^T matrices from SVD decomposition results which are ready for 
# generating CVs of rank 125, 25, and 343. The CVs are generated by 
# np.matmul(Vt, vrK), in which vrK is the sorted eigenvector matrix from 
# diagonalizing Koopman matrix. Check Ala2-RMSE_n_CV.ipynb in the section 
# "CVs v.s. Ramachandran angles" to see the general method of how these 
# files are generated.

Ala-lag0.1ps-first5tICs-msmbuild.npy:
# A 3D np.array with shape (100, 100001, 5). Generated with the function
# "tICA(lag_time=10, n_components=5)" in library msmbuilder.decomposition. 
# The original MD has 100 trajectories with 100,001 frames in each of them.
# Timestep is 0.1 ps between frames.

ala_rama_all_1ps.txt:
# Ramachandran phi and psi angles for 10,001 frames with 1ps timestep. See
# usage in Ala2-RMSE_n_CV.ipynb, section "CVs v.s. Ramachandran angles".

Koopman_bootstrap.npz:
# CK test intermediate results. Has 3 keys: "Koop_boot" saves a 4D np.array 
# which is the matrices during bootstrapping; "lag" saves the corresponding
# lag times; "note" is the note. Check Ala2-tICsGaussian_n_bootstraping.ipynb,
# which is the notebook generating this .npz file, for more information.

KoopmanMat-2-2-0-mix.npz:
# Contains rank 125 Koopman matrices, which has the basis list from using the
# first 2 tICs and 2 Gaussian functions, and then expanded to tIC 3. Has 3
# keys: "lag_times", "basis_list", and "Ks", which are lag times, basis list,
# and Koopman matrices, respectively.

Ks25.npy:
# A 3D np.array of shape (50, 25, 25), which are 50 matrices of 25*25 shape
# for lag time from 1ps to 50ps. Check Ala2-dim25-KoopmanGeneration.ipynb,
# which is the notebook generating this .npy file, for more information. 

random-number-100.txt:
# Random numbers, generated by website random.org. Used in CK test. Check 
# Ala2-tICsGaussian_n_bootstraping.ipynb for more information about usage.

Ala2_pred60lag-mode[1/2]_[color/data].txt:
# Data files for CV plotting, i.e. Ramachandran plots. They are the top 2 CVs
# under parameters tau_k=13, L=8, prediction_steps=60 frames, 1 frame = 1 ps.

Panel_*.npz:
# These files are results for each plot, and they are finally used for plots.
# Notebook Ala2-AllPlots.ipynb take them as input.

\svg_files\*.svg:
# Output from Ala2-AllPlots.ipynb, combined together into figures shown in the
# paper draft with Inkscape.
